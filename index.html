Diet & Nutrition Planner System

Developed a full-stack Diet & Nutrition Planner System as part of a team project, designed to connect users with nutritionists through a centralized web platform. Nutritionists can create and manage diet plans, review user requests, and approve suitable plans. Users can register, securely log in, browse available plans, apply by providing health and lifestyle details, and track request status. Key features include JWT-based authentication and authorization, role-based access for Users and Nutritionists, diet plan management, request and approval workflow, feedback management, form validation, secure API communication, and centralized data management using MS SQL Server. The project provided practical experience in full-stack development, RESTful APIs, dependency injection, database operations, Angular components and forms, and debugging application-level issues.
